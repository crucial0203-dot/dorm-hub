三步开局（30 秒）

  1. 房主进入 骗子博弈 → 输入昵称 → 点「创建房间」。
  2. 房主把房间页中央的4 位房间号（或二维码）发到寝室群 / 微信。
  3. 舍友打开同一链接 → 输入房间号 + 昵称 → 「加入」。≥3 人即可开局，中途加入也算一员。

连不上？三招排查

  1. 同一 WiFi / 热点 → 99% 直连成功，寝室场景首选。
  2. 异地 / 校园网 → 本站默认已启用 TURN 中继与 Cloudflare STUN；仍不通时可在牌局页底部注入自定义 TURN（公共 OpenRelay 免注册，详见 NETWORK.md）。
  3. 微信内置浏览器可能屏蔽 WebRTC → 复制链接到 Chrome / Safari / Edge 打开。

对局中请避免熄屏 / 切后台，否则 WebRTC 连接会中断；房主断线会自动迁移给下家，同名重进可恢复对局。

关于

骗子博弈来自开源仓库 lu123bing/liars-gambit，由寝室运营一本通集成；麻将基于 Pomax 的开源实现。三国杀基于开源项目「无名杀 noname」（GPL-3.0，github.com/libccy/noname）静态化集成，联机使用其官方服务端。所有通信走浏览器 P2P（WebRTC + PeerJS），没有服务器、没有账号，数据只在你和舍友的设备之间流动。
